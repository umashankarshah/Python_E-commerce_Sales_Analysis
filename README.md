# 📊 Amazon Sales Analysis

## Overview

This project analyzes Amazon sales data to uncover insights related to revenue, cancellations, fulfillment performance, and customer purchasing behavior. The objective is to identify business opportunities and provide data-driven recommendations to improve sales and customer experience.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* 
## Analysis Performed

* Data Cleaning & Preprocessing
* Revenue Analysis by Category and State
* Cancellation Analysis
* Fulfillment Performance Analysis
* Average Order Value (AOV)
* Product Size Distribution
* Sales Channel Analysis

## key insights
T-shirts were the top revenue-generating category.
Sales were concentrated in a few states, with Maharashtra among the top contributors.
Order cancellations led to significant revenue loss.
Fulfillment method impacted cancellation rates and order success.
Customer demand was concentrated around specific product sizes and categories.
## Recommendations
Focus inventory on top-performing categories.
Reduce cancellations by improving fulfillment processes.
Invest marketing efforts in high-revenue states.
Monitor key metrics such as Revenue, AOV, and Cancellation Rate.
Use demand trends to optimize inventory and improve customer experience.
